# Rawat Bakery Website

A simple, responsive bakery website made with plain HTML and CSS. No installation or build tools are needed.

## Preview

Open `index.html` in a web browser.

## Before publishing

In `index.html`, replace the sample address, phone number, opening hours, and email address in the Contact section with the bakery’s real details. The hero photo loads from Unsplash, so it needs an internet connection.

## Upload to GitHub

1. Create a new repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and this README from this folder.
4. Commit the changes.
5. To publish it, open the repository’s **Settings → Pages** and choose the `main` branch and `/ (root)` folder.
